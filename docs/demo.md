# Demo

Run `pip install -r requirements.txt`, then `python backend/app.py` and open `http://127.0.0.1:5000`.

Click **Load Demo** and then **Analyze Response**. The dashboard displays the reliability score, claim verdict, evidence, hallucination type/severity, correction, and re-verification.

Suggested demo inputs:
- `Paris is the capital of France.`
- `Paris is the capital of Germany.`
- `The Pacific Ocean is the largest ocean on Earth.`
- `Python was created by James Gosling.`
